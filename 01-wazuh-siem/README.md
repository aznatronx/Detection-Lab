##What is Wazuh
**Wazuh is a free program that protects computers and servers.** It works like a digital security guard: it watches for trouble, looks for bugs, and warns you about threats.

##What Wazuh Does
- **Checks logs** — reads computer "diaries" to spot strange behavior.
- **Finds weaknesses** — looks for old software that hackers could use to break in.
- **Watches files** — sounds an alarm if someone changes important system files.
- **Stops attacks** — can automatically block a hacker or turn off a sick computer.

#How it Works (Architectures)
1. **Agent** — a small scout program. It is installed on each computer that needs to be monitored.
2. **Server** — the "brain" of the system. It collects reports from agents and looks for threats in them.
3. **Dashboard** — a nice website with graphs where a human administrator sees everything that is happening.
